# Iron PGN Parser

This program has been made in reaction to `python-chess`'s slowness. 200 games/s is not enough when analyzing the ***8.2 B games*** on `lichess.org`. As of now, I have gotten a 2.5x improvement over the python implementation. Of course, my parsing is unchecked, so unexpected errors may occur. 

> [!WARNING]
> This program is in pre-alpha, expect breaking changes at a regular pace.

## Usage
Since there is no stable API as of now, you are mostly on your own. 
Good luck!
